# Contributing

1. Create a focused branch for your change.
2. Install development dependencies with `python -m pip install -e ".[dev]"`.
3. Run `python -m pytest` and `ruff check .` before opening a pull request.
4. Keep changes documented when they affect architecture, configuration, or
   public behavior.

Please avoid committing credentials, customer data, or other sensitive
information. See [SECURITY.md](SECURITY.md) for reporting vulnerabilities.
